# EduTools

A responsive, static landing page for free education tools. It explains the
EduTools approach and clearly discloses that the software is generated by AI
from prompts informed by education IT experience.

## Preview

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript;
no build step or package installation is required.

## Adding software and documentation links

Open `download-links.js` and set each product's URL or relative path. For
EduHelpdesk, `helpdesk` is the installer and `helpdeskDocs` is its
documentation:

```js
window.EDUTOOLS_DOWNLOADS = {
  eduresourcer: "https://example.com/eduresourcer.html",
  eduexamwriter: "",
  helpdesk: "https://example.com/edusoftware-helpdesk-installer.zip",
  helpdeskDocs: "https://example.com/edusoftware-helpdesk-docs",
};
```

Each download or documentation button becomes active automatically when its
link is provided. Keep a value empty to leave that button unavailable until
the URL is ready.

## EduHelpdesk page

Open `helpdesk.html` directly to preview the EduHelpdesk product page. It uses
the shared site stylesheet and navigation, with additional styles in
`helpdesk.css`.
